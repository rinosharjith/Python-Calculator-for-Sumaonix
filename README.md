# 🧮 Python Simple Calculator

A beginner-friendly calculator built using Python to practice and understand **arithmetic operators**.

This project takes two integer inputs from the user and performs different mathematical operations, displaying the results in the terminal.

## ✨ Features

The calculator supports the following arithmetic operations:

- ➕ **Addition (`+`)** – Adds two numbers.
- ➖ **Subtraction (`-`)** – Finds the difference between two numbers.
- ✖️ **Multiplication (`*`)** – Multiplies two numbers.
- ➗ **Division (`/`)** – Divides the first number by the second.
- 🔢 **Floor Division (`//`)** – Returns the quotient rounded down.
- ⚡ **Exponentiation (`**`)** – Raises the first number to the power of the second.
- `%` **Modulus (`%`)** – Returns the remainder after division.

## 🛠️ Technologies Used

- Python 3
- Built-in `input()` and `print()` functions
- Python arithmetic operators

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/rinosharjith/Python-Calculator-for-Sumaonix.git
   ```

2. Open the project folder:

   ```bash
   cd Python-Calculator-for-Sumaonix
   ```

3. Navigate to the Python file:

   ```bash
   cd Python_Calculator
   ```

4. Run the program:

   ```bash
   python app.py
   ```

   If your system uses the `python3` command, run `python3 app.py` instead.

5. Enter two integer values when prompted and view the results.
